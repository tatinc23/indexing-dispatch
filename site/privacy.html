Privacy

Indexing Dispatch, run by TAT Inc. Updated October 31, 2026.

What the server keeps

  • For each Brave submission the server keeps one log line: the page address without anything after a ?, the result, any error code, and how long it took.
  • Nothing about who sent it, and no request headers.
  • The other tools log only the tool name, the result and timing. The IndexNow tool also logs the host and how many URLs.

Who else sees what

  • Brave receives the URL you submit, which is the point.
  • The server runs on Cloudflare Workers (the Brave tool uses Cloudflare’s browser service), and Cloudflare may keep its own logs.
  • The audit requests your page and its robots.txt, llms.txt and sitemap, identifying itself as indexing-dispatch-audit/1.0.

This website

  • This page has no cookies and no analytics.
